📖 Step-by-Step Setup Instructions (Click to expand)
  1. Go to gist.github.com and sign in with your GitHub account
  2. Click "Create gist" (top right or + icon)
  3. Set description to: CTF Data Storage
  4. Set filename to: ctf-data.json
  5. Paste this as content: {"adminPass":"admin123","studentPass":"pslog2025","students":[]}
  6. Click "Create secret gist" (NOT public!)
  7. Copy the Gist ID from the URL:
    https://gist.github.com/YOUR_USERNAME/abc123def456...
    → Copy the long random part (e.g., abc123def456789)
  8. Go to GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
  9. Click "Generate new token" → "Generate new token (classic)"
  10. Set note: CTF Sync, expiration: No expiration
  11. Check ONLY "gist" permission (under the gist section)
  12. Click "Generate token" and COPY IT IMMEDIATELY (you won't see it again!)
  13. Paste both values below and click Save
